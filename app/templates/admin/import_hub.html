1 Tải File Mẫu Chuẩn (Excel / JSON)

Tải file mẫu về máy, điền dữ liệu học tập của bạn vào các cột/trường tương ứng rồi nạp lên ở Bước 2.

Loại Dữ Liệu Các trường thông tin chuẩn Tải File Mẫu
📗
Từ vựng (Vocabulary) Dùng cho Flashcard, Tra cứu & Games
word, pronunciation, part_of_speech, meaning_vi, example_en, example_vi, topic, level (A1-C2), collocations, synonyms
Excel (.xlsx) JSON (.json)
📘
Ngữ pháp (Grammar) Cẩm nang & Quy tắc ngữ pháp
title, category, level, difficulty (Easy/Medium/Hard), summary, rule_explanation, examples_json, common_mistakes, tips_tricks
Excel (.xlsx) JSON (.json)
📙
Bài học (Lessons) Bài giảng các kỹ năng & khóa học
title, level (A1-C2), skill (Writing/Speaking/Reading/Listening...), short_description, content (Markdown), examples, thumbnail_url
Excel (.xlsx) JSON (.json)
📕
Câu hỏi & Bài tập (Questions) Ngân hàng trắc nghiệm & Quiz
question_text, option_a, option_b, option_c, option_d, correct_option (A/B/C/D), explanation, topic, level
Excel (.xlsx) JSON (.json)
📓
Đề thi (TOEIC / IELTS Exams) Đề thi thử & bài kiểm tra trọn gói
category, title, duration_minutes, difficulty, skill, part, question_text, option_a..option_d, correct_answer, explanation
Excel (.xlsx) JSON (.json)
