Tự động bắn thông báo lỗi HTTP 500 hoặc sự cố hệ thống nghiêm trọng qua Telegram Bot, Discord Webhook hoặc Slack.

Khi bật, mọi lỗi nghiêm trọng sẽ được chuyển tiếp tức thời tới các kênh bên dưới.

Hướng dẫn Tích hợp Cảnh báo
Tạo Telegram Bot: 1. Nhắn tin /newbot cho @BotFather trên Telegram.
2. Sao chép API Token dán vào ô bên trái.
3. Thêm bot vào nhóm và lấy Chat ID thông qua @userinfobot.
Tạo Discord Webhook: 1. Vào Server Discord → Edit Channel → Integrations.
2. Bấm Create Webhook và dán URL vào ô Discord.
Cơ chế Chống Spam (Anti-Flood): Hệ thống tự động gom nhóm lỗi theo Fingerprint và áp dụng thời gian chờ Cooldown, đảm bảo người quản trị không bị làm phiền bởi hàng trăm thông báo giống nhau.
